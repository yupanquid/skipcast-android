# SkipCast - Android APK Cloud Build Package

This repository is pre-configured to automatically compile the **SkipCast** React application into a native Android `.apk` using **Capacitor** and **GitHub Actions** in the cloud.

## How to Get Your Installable `.apk` File (No Coding or Software Required)

1. **Unzip this folder** on your computer.
2. Sign in to [GitHub.com](https://github.com/) and create a **New Repository** (name it `skipcast-app`).
3. Click **uploading an existing file** on the repository setup screen and drag-and-drop **all files and folders** from the unzipped folder (make sure to include the `.github` folder!).
4. Click **Commit changes**.
5. Click the **Actions** tab at the top of your GitHub repository.
6. You will see the **Build SkipCast Android APK** workflow running. Wait ~2–3 minutes for it to turn green.
7. Click on the completed workflow run and scroll down to **Artifacts** -> click **SkipCast-Android-APK** to download your `.apk`!
